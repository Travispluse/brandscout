## Direction (options for the maintainer, not ranked against bugs)

1. **Decide what the public API is for, then finish or cut it.** The repo signals an agent-callable API (`src/app/api/openapi.json/route.ts`, `src/app/.well-known/ai-plugin.json/route.ts`, `src/app/docs/page.tsx`, a Dashboard API-key generator, `X-API-Key` in CORS headers), but keys are never read, usage is never counted, and the spec has drifted (B4). Real keys plus per-key quotas would turn the existing route into a product. Removing the key UI is the cheap honest alternative. Coarse effort: M–L for keys/quotas, S to remove.
2. **Search history is written but never read.** Every `/api/search` call persists `Search → Candidate → DomainCheck/UsernameCheck` rows when `DATABASE_URL` is set (`src/app/api/search/route.ts:35-73`, `prisma/schema.prisma`), and nothing reads them. Either build on the data (server-side watchlist re-checks that actually notify, instead of re-checking only when `/saved` is open, which is the B1 code path; "recently checked names" pages) or drop Prisma and the write path. Dropping it also removes a dependency chain. Coarse effort: M to use, S to remove.
3. **Make the analysis a single server-side engine.** `/api/v1/check` already returns pronunciation, strength, sentiment, trademark and market analysis. The website recomputes overlapping heuristics client-side (B11). Returning one analysis object from both routes would fix the contradictions, and gives a single place to swap the word-list trademark heuristic for a registry-backed check later (B2). Coarse effort: M.

## Findings considered and rejected

- Workflow script injection via `inputs.topic`: not present. The input reaches the script through `env: TOPIC`, not `${{ }}` inside `run:` (`.github/workflows/daily-blog.yml:39-45`).
- Path traversal through LLM-generated slugs: `slugify` restricts slugs to `[a-z0-9-]` (`scripts/generate-daily-blog.mjs:67-75`).
- Share-link base64 `+`/`/` corruption: round-trip tested, decodes correctly.
- Analytics/site-verification IDs in `src/app/layout.tsx`: public client-side identifiers, not secrets.
- Facebook always "unknown" and Discord skipped, which caps the platform score below 40: deliberate conservative behavior, documented in code comments (`src/lib/username-check.ts:108,177`).
- Prisma 6 → 7 major upgrade: not worth it now. Prisma usage is optional (`src/lib/prisma.ts` returns `null` without `DATABASE_URL`). Revisit together with Direction 2.
